## Data Visualization Project

This project demonstrates different types of data visualization techniques using Python libraries such as Matplotlib, NumPy, Seaborn, and Basemap.

## Features
Histogram visualization
Line plots with colors
Text and annotation in graphs
3D scatter plot
World map visualization using Basemap
Seaborn scatter plot
## Technologies Used
Python
Matplotlib
NumPy
Seaborn
Basemap
## Installation
Install the required libraries using:
pip install matplotlib numpy seaborn basemap
## Run the Project
Execute the Python file:
python data_visualization.py
## Output

The project generates:

Histograms
Line charts
3D plots
World maps
Seaborn visualizations
